problem:
so sometimes representative_point() gives a point!

and sometimes:
rp is a shapely.coords.CoordinateSequence object

there may be more than one so
rep_point[0]

it has a coords attribute


https://github.com/shapely/shapely/issues/984
so we want
t = rep_point[0].coords[:][0]

and then can do
x,y,_ = t

actually, if rp is a CoordinateSequence it's easier to do:
list(rp)

work with the gdf

import geopandas as gpd

dbpath = '/Users/telliott/Library/CloudStorage/Dropbox/maps5/lewis_clark/'
LC = gpd.read_file(dbpath + 'doc.kml',
    driver='LIBKML')

def f(e):
    return e.representative_point().coords[:][0]

gdf = LC['geometry'].apply(f)

>>> gdf
0     (-113.1762060005872, 47.00538999905787, 0.0)
1     (-91.75296140877758, 38.69352509459112, 0.0)

>>> type(gdf)
<class 'pandas.core.series.Series'>
>>> 


Bottom line
representative_point depends on the object
if it's a CoordinateSeries, do list(rp)
